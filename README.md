# 🇰🇿 Қазақстан тарихы — ҰБТ 2026

Қазақстан тарихынан ҰБТ-ға дайындалуға арналған қазақша веб-платформа.

## Қосылған мүмкіндіктер

- **510 сұрақтық тапсырма банкі** — 51 тарихи факт негізінде 10 нұсқадан
- **ҰБТ режимі** — 20 кездейсоқ сұрақ және 15 минут таймер
- Тақырып бойынша тест
- Аралас кездейсоқ тест
- Автоматты бағалау және қате жауаптарды талдау
- **Оқушы кабинеті** — тест тарихы, орташа және соңғы нәтиже
- **Мұғалім кабинеті** — браузерде сақталған нәтижелерді көру және CSV экспорт
- **Рейтинг** — осы браузердегі нәтижелер бойынша
- Нәтижелерді `localStorage` арқылы сақтау
- Қараңғы режим
- Мобильді дизайн
- GitHub Pages-ке дайын

## Файлдар

- `index.html` — интерфейс
- `style.css` — дизайн
- `data.js` — 510 тапсырмаға арналған сұрақтар базасы
- `script.js` — тест, аккаунт, тарих, рейтинг және экспорт логикасы

## GitHub Pages

**Settings → Pages → Deploy from a branch → main → / (root) → Save**.

> Ескерту: бұл нұсқада аккаунттар, рейтинг және нәтижелер серверде емес, пайдаланушының браузерінде сақталады. Шынайы көпоқушы/мұғалім жүйесі үшін Firebase/Supabase сияқты дерекқор және авторизация қосу қажет. Сұрақтарды ресми ҰБТ материалдарымен сәйкестігін мұғалім тексеріп, толықтыра алады.
