# 🇰🇿 Қазақстан тарихы — ҰБТ 2026

Қазақстан тарихынан ҰБТ-ға дайындалуға арналған толықтай браузерде жұмыс істейтін оқу платформасы.

## Мүмкіндіктер

- Тақырып бойынша тест
- Аралас кездейсоқ тест
- 15 минуттық таймер
- Автоматты бағалау
- Қате жауаптарды талдау
- Үздік нәтиже мен тест санын сақтау (`localStorage`)
- Қараңғы режим
- Мобильді құрылғыларға бейімделген интерфейс
- GitHub Pages арқылы орналастыруға дайын

## Файлдар

- `index.html` — интерфейс
- `style.css` — дизайн және responsive layout
- `script.js` — тест логикасы және сұрақтар базасы

## GitHub Pages

Repository → **Settings → Pages** → Source: **Deploy from a branch** → Branch: **main** → Folder: **/ (root)** → Save.

Содан кейін GitHub Pages беретін мекенжай арқылы сайт ашылады.

> Ескерту: бұл оқу-жаттығу платформасы. Сұрақтар базасын ресми ҰБТ материалдарымен сәйкестігін мұғалім тексеріп, толықтыра алады.
